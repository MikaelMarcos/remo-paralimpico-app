# Remo Paralímpico: app do atleta (Android)

Aplicativo para atletas de remo paralímpico. Preso no barco, com a tela
de frente para o atleta, o celular conta as remadas (câmera ou acelerômetro), registra o percurso
pelo GPS e envia os dados ao vivo para o painel do treinador.

## Como instalar

1. No celular Android, abra a página de **[Releases](../../releases/latest)** deste repositório.
2. Em **Assets**, toque no arquivo:
   - **`remo-paralimpico-arm64.apk`**: a maioria dos celulares (2017 em diante);
   - **`remo-paralimpico-armv7.apk`**: só se o primeiro não instalar (celulares mais antigos).
3. Quando o Android perguntar, permita **"Instalar apps desta fonte"** para o navegador.
4. Toque em **Instalar** e depois em **Abrir**.
5. Digite o **código da equipe** (peça ao treinador) e o seu nome.

O aplicativo é gratuito, não tem anúncios e o vídeo da câmera **nunca sai do celular**.
